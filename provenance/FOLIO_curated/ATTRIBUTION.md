Source: DSAVlab-UNIUD/FOLIO_validation-curated, public author-curated FOLIO validation annotations associated with Andrea Brunello, Cristian Curaba, Luca Geatti, Michele Mignani, Angelo Montanari and Nicola Saccomanno, *Fixing FOLIO and MALLS: Verified Annotations and an LLM-assisted Framework to Focus Human Relabeling* (2026).

The bundled source README declares CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ . See provenance.json for the exact retrieved commit, paths, URLs and SHA256 hashes. Data bytes are unchanged. Evaluation uses the actual `FOL_sentence_new` field in the release, rather than assuming README field spelling.

This release comprises 73 story rows and 202 conclusion rows. The original FOLIO dataset's authors are credited through the source publication/repository. This artifact does not relabel the examples and does not assert that a recorded solver disagreement proves a human-language annotation error. This public curated release is distinct from both the earlier legacy v0.0 release and the official gated revised dataset.
