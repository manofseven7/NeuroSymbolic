# RuleTaker NatLang / ParaRules source

Original release: `rule-reasoning-dataset-V2020.2.5.zip`, distributed by Allen Institute for AI through the dataset link in https://github.com/allenai/ruletaker . The exact URL, archive SHA256 and unmodified selected-file hashes are in provenance.json. README_upstream.md is the release README, retained unchanged. The archive uses the internal folder name V2020.2.5.0. We use its **original/NatLang** files, not a silently substituted ProofWriter or Problog release.

Cite: Peter Clark, Oyvind Tafjord and Kyle Richardson (2020), **Transformers as Soft Reasoners over Language**, IJCAI 2020, 3882–3890, DOI 10.24963/ijcai.2020/537, https://www.ijcai.org/Proceedings/2020/0537.pdf .

The repository's Apache 2.0 software notice is preserved as LICENSE_repository; this does not assert an independently verified license for every upstream dataset artifact. Original third-party rights remain with their owners. No endorsement by upstream authors is implied.

The original theories include crowdworker paraphrases and canonical logic metadata. Question labels use binary closed-world semantics. Numeric IDs are local to each split and repeat across train/dev/test; use split-qualified IDs and content hashes. Research outputs, automatically reconstructed rule units and annotations are separate from these unmodified files. Canonical metadata is an evaluation/annotation reference, not independent human adjudication of every paraphrase's meaning.
